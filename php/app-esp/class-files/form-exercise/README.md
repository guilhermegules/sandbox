# Trabalho Formulário PHP

## Regra de negócio:

Utilizar include ou required

include (exemplo de aplicacao)
fazer um função que faça login

Crie um arquivo chamado login.php com validação.
armazenar na sessão o id_sessao + nome
campos usuario e senha

Crie um arquivo chamado cliente.php.
Mostrar no topo da pagina o nome e numero da sessao

Neste arquivo, crie um formulário que será enviado via post
para um arquivo chamado salvar.php em cookie

Coloque os seguintes campos no formulário:

- Nome
- Endereço completo (vc deve separar os campos)
- CPF
- RG
- Data de nascimento
- Sexo (Radio button)
- Observações (campo para texto longo)
- Preferência de browser[Checkbox]
- Botão de envio e reset

De preferência alinhe o formulário em uma tabela HTML
