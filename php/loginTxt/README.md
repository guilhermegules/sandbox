## Login System with php

> Making a login system with php with redirect and txt storage.

- For run this version you need [xampp server](https://www.apachefriends.org/pt_br/index.html);
- And put this directory in `/opt/lampp/htdocs/php_playground/PHP_Playground`;
- And finally go to this address `http://localhost:8080/php_playground/PHP_Playground/loginTxt/src/` obs this port `8080` has been defined manually :D.
