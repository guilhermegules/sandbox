# DevOps Playground

Personal repository for studying DevOps concepts, Linux system administration, Bash scripting, Kubernetes, networking, and system monitoring.

## Repository Structure

| Directory                    | Description                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| [`kubernetes/`](kubernetes/) | Kubernetes core concepts, architecture, and object documentation                                                          |
| [`linux/`](linux/)           | Curated Linux learning resources and roadmaps, Bash scripting exercises, Linux command references, and automation scripts |
| [`network/`](network/)       | Networking fundamentals, OSI model layers, and hands-on activities                                                        |

## Topics Covered

- **Linux**: Filesystem hierarchy, basic commands, system administration
- **Bash Scripting**: Automation scripts, user management, file operations
- **Kubernetes**: Pods, Deployments, Services, ConfigMaps, Secrets, desired state
- **Networking**: OSI model, network layers, connectivity testing

## Getting Started

Each subdirectory contains its own `README.md` with detailed content. Navigate to the relevant folder to explore specific topics.
