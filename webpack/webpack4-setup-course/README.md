# Webpack 4: Beyond the Basics Course

## Learnings:

- entry purpose - indicates the entry point of our application, using the `main` property;
- mode purpose - indicates the each mode webpack will render `"development" | "production" | "none"`;
- output purpose - will let the output folder;
  - `filename` property is the name of the builded file name;
  - `path` with this property we can define the output of the js file;
  - `publicPath` this property is optional, we can use this for declare a custom path from JavaScript file.
- devServer - In this object we can add the dev server config
  - `contentBase` - this property will define the which directory dev server webpack will be watching
