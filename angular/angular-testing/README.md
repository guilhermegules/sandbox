Some tests developed to Angular, for better knowledge of tools

## Types of tests
- Unit Test
    - Simplest test type;
    - Test specific components of the system;
        - Classes, modules, functions...
    - Isolated.
- Integration Test
    - Checks whether individual components work properly together;
    - Focuses on interation between components.
- End-to-end Test
    - Test the whole system to make sure it properly uses allocated resourses;
    - Make sure all the features are working correctly from the user perspective.
