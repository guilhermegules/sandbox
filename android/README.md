## About Android

- Operating system for mobile devices maintained by Google since 2005;
- Over 2.5 billion active users;
- Present in more than 24,000 different device models;
- Cars, clothing, TVs, refrigerators and even mirrors;
- Last available version: Android 11 (July 2, 2020).

## Curiosities

- Android 3.0 (Honeycomb) - only version exclusively for tablets;
- The characteristic look of android appeared in the Ice Cream Sandwich version;

## Kotlin

- Made by JetBrains in 2011, maintened by Kotlin foundation;
- Multiplatform, Object oriented and functional language;
- Free and open source;
- Kotlin is a tribute a Russian island.

### Language structure
 
- Does not use semicolons;
- No traditional ternary operator;
- Type safe and null safe;
- Type inference.

### Applicability

- Native Android;
- Multiplataform mobile (KMM);
- Framewoks:
  - [Kvision](https://kvision.io/);
  - [Fritz2](https://www.fritz2.dev/).
- Backend with target Node.js Kotlin/js 

### Benefits

- Safe, structured, less verbose, more optimized, great relevance in the market;
- Interoperability with JAVA;
- Smart casts and null safety;
- Android is Kotlin first.

### Kotlin + Android

- 2016: First stable version of Kotlin is released;
- 2017: Google announces support for Kotlin for Android development;
- 2018: Segunda linguagem preferida dos desenvolvedores (by stackoverflow research);
- 2019: Google announces that Kotlin is the new official language for Android development.
