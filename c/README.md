# prog-c

Algorithms and study with C language

## Alocação estática vs dinâmica

- Estatimente a memória será alocada desde o inicio da aplicação;
- Dinamicamente a memória será alocada em tempo de execução;

## How run

- `ctrl + shift + p` select the compiler to build your application in VSCode;
- `ctrl + shift + b` for build our file;
- run `./your-file` will run the C/C++ binary
