Equal-height Flex Cards with Sticky Headers

Cards stretch to the tallest in each flex row. Headers stick inside each card while only the content area scrolls.

How it works: the card is a display:flex column. The middle .card__content flexes and becomes the scroll container (overflow:auto), so the header can be position:sticky; top:0. The outer grid uses a flex row with align-items:stretch so cards match height per row.
