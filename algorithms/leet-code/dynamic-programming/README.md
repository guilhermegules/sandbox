# Dynamic Programming

DP becomes obvious when you start asking this:

> "Am I solving the same subproblem multiple times?"

Instead of re-checking again and again, DP says:

> "If I already know how many repeats end before this, I can reuse it."

That’s the mental shift.

## Learn to spot overlapping work

Before jumping to DP, always try brute force and ask:

- Am I recalculating something?
- Can I store it?
